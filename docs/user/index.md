# User Guide

End-user documentation for QtDMM: installation on Debian/Ubuntu, Arch and RPM
based systems, connecting a meter over serial, USB-HID, RFC2217 or sigrok, the
settings dialog (vendor and model selection, manual port settings), the transient
recorder, thresholds and the external-command trigger, CSV import and export, and
printing.

The content has not been written yet. Until it is, the `qtdmm(1)` man page and
the project README cover the command-line options and the list of supported
hardware.
