# Keyboard and mouse

Every toolbar button shows its shortcut in the tooltip. Shortcuts of the
main window work while it is the active window, whichever panel has the
focus.

## Main window

| Key | Action |
|---|---|
| Ctrl+C or Ctrl+D | Connect / disconnect the meter |
| Ctrl+S | Start the recorder |
| Ctrl+X | Stop the recorder |
| Space | Start the recorder, or stop it when it is running |
| Ctrl+Del | Clear the recording |
| Ctrl+R | Reset the min/max memory |
| Ctrl+E | Export the recording as CSV |
| Ctrl+I | Import a CSV file |
| Ctrl+P | Print the graph |
| Ctrl+Shift+C | Copy the graph as an image to the clipboard |
| F2 | Settings |
| Shift+F2 | Settings, Multimeter page |
| Ctrl+F2 | Settings, Recording page |
| Ctrl+N | Manage instances |
| Ctrl+M | Open the menu |
| F1 | This handbook |
| Shift+F1 | Direct help — then click any control for an explanation |
| Ctrl+T | Tip of the day |
| Ctrl+Q | Quit |

## Panels and window

| Key | Action |
|---|---|
| Ctrl+1 | Show / hide the digital display |
| Ctrl+2 | Show / hide the analog meter |
| Ctrl+3 or Ctrl+G | Show / hide the recorder graph |
| Ctrl+4 | Show / hide the readings table |
| Ctrl+L | Lock / unlock the panels (hides their title bars) |
| F11 | Full screen on / off |

## Graph

The zoom shortcuts work anywhere in the main window; the plain keys
(`+`, `-`, `0`, arrows, Home, End) after a click into the graph.

| Input | Effect |
|---|---|
| Ctrl++ / Ctrl+- or + / - | Zoom the time axis in / out |
| Ctrl+0 or 0 | Show the whole recording |
| ← / → | Pan by a tenth of the visible window; with Shift by half |
| PgUp / PgDn | Pan by a whole window |
| Home / End | Jump to the start / end of the recording |
| Mouse wheel | Zoom the time axis |
| Middle button drag | Pan the time axis |
| Hover | Crosshair with time and value |
| Left button drag on a threshold line | Move the threshold |
| Right button | Menu: connect, start/stop, clear, configure, copy image, import/export |

## Readings table

While the table has the focus:

| Key | Action |
|---|---|
| Ctrl+C | Copy the selected rows (all when nothing is selected) as tab-separated text |
| Ctrl+A | Select all rows |

## Settings dialog

| Key | Action |
|---|---|
| Ctrl+PgUp / Ctrl+PgDn | Previous / next page |
| Alt+U | Undo the changes made since the dialog was opened |
| Alt+F | Factory defaults for the current page |
| Enter / Esc | OK / Cancel |

## Handbook window

| Key | Action |
|---|---|
| Alt+← / Alt+→ | Back / forward |
| Alt+Home | Table of contents |
| Ctrl+F | Search in the page |
| Enter or F3 | Next match, Shift+Enter or Shift+F3 the previous one |
| Esc | Close |

## Instances dialog

| Key | Action |
|---|---|
| Ins | Add an instance |
| Del | Remove the selected instances |
| Ctrl+F | Add a calculated instance (ƒ) |
| Esc | Close |

## Tip of the day

| Key | Action |
|---|---|
| ← / → | Previous / next tip |
| Esc | Close |
